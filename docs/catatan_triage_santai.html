2. Yang Udah Dikerjain & Beres di Sisi Frontend

Semua perubahan di bawah ini udah ditest di berbagai ukuran layar (HP 375px, Tablet 768px, Laptop 1280px) dan lulus 100%:
  • Warna Baru Emerald Green Apotek: Warna dasar biru udah diganti total jadi hijau emerald khas apotek herbal/kesehatan (#059669), lengkap sama ilustrasi gedung apotek baru di login dan dashboard. Background langit login juga udah dikasih gradasi awan lembut biar gak flat polosan.
  • Tombol "Kembali" Aktif: Di pojok kiri atas header sekarang udah ada tombol Kembali di semua menu (kecuali login dan dashboard utama), jadi user gak bingung pas mau balik ke menu sebelumnya.
  • NIB & CDOB Bersih: Kolom NIB di profil/pengaturan, cetak Berita Acara (BAP), dan sidebar udah dicopot. Tulisan klaim "Standar CDOB BPOM" juga udah diganti keterangan biasa ("Kisaran Timur").
  • Label "Data Simulasi" & Hapus "Mode Lokal": Di header atas udah nempel badge Data Simulasi. Terus tulisan Mode Lokal di menu faktur udah dihapus tuntas.
  • Aksi Nyata Batch & Kurang Stok: Pas tombol retur atau buang obat diklik, sekarang muncul popup modal buat konfirmasi jumlah dan catatan. Begitu disimpan, stok obat otomatis terpotong dan obatnya langsung hilang dari daftar pengingat tanpa perlu refresh web.
  • Tombol Khusus Obat Lewat Batas: Kalau obat udah lewat batas retur PBF, tombolnya otomatis berubah: kalau belum kedaluwarsa jadi Prioritas Jual (taruh etalase depan/diskon), kalau udah kedaluwarsa jadi Catat Dibuang (pemusnahan obat).
  • 4 Kategori Rapi & Seragam: Semua halaman sekarang cuma pake 4 status baku: Bisa Diretur, Lewat Batas Retur, Dekat ED, dan Stok Tipis. Kalau obat udah lewat batas, badge "Risiko Tinggi" otomatis disembunyiin biar gak tabrakan.

3. Contekan Pesan Santai Buat Temen Backend (Tinggal Copy-Paste)

Tinggal copas aja pesan di bawah ini ke grup WA/Discord/Slack kalian, bahasanya udah santai kaya temen nongkrong:

🔒 1. Soal API Key Gemini OCR (#3) Penting
"Bro, buat API Key Gemini nanti jangan ditaruh di frontend ya, bahaya bisa dicolong orang lewat Inspect Element browser. Tolong bikinin satu endpoint proxy di backend kita, misalnya POST /api/v1/faktur/ocr-gemini. Jadi API key-nya aman disimpan di file .env server. Nanti dari frontend tinggal kirim file fotonya aja ke endpoint itu."
📦 2. Endpoint Catat Retur, Dibuang, & Prioritas Jual (#7, #8, #9) Kebutuhan Database
"Bro, di frontend alur retur sekarang beneran nyatet aksi riil, bukan cuma pajangan atau pindah layar. Tolong bikinin transaksi database atomik di backend:
  • POST /api/v1/retur : Buat nyatet retur obat. Stok di tabel batch dipotong, catat ke log riwayat retur, dan kalau stoknya jadi 0, tandai obatnya udah selesai diretur.
  • POST /api/v1/batch/:id/buang : Buat obat lewat batas yang beneran udah ED. Stok dinolkan dan catat log pemusnahan.
  • PATCH /api/v1/batch/:id/prioritas-jual : Buat nambah flag bahwa obat ini dipajang di etalase depan buat dijual cepet.
  • Filter Pengingat: Tolong di query GET /api/v1/pengingat, jangan tampilin lagi obat yang stoknya udah 0 atau statusnya udah diretur/dibuang ya, biar lonceng notifikasi dan pengingatnya bersih."
🏷️ 3. Format 4 Kategori Status & Kolom NIB (#4, #10, #11, #12) Penyelarasan API
"Satu lagi bro:
  • Format status obat di respons JSON pengingat tolong dibagi 4 grup biar sinkron sama UI: bisa_diretur, lewat_batas_retur, mendekati_kedaluwarsa, sama stok_menipis.
  • Kalau obat statusnya udah masuk lewat_batas_retur, gak usah dikasih status risiko 'tinggi' lagi ya biar labelnya gak tabrakan di layar.
  • Kolom nib di tabel profil apotek dibikin opsional/nullable aja ya, soalnya di UI udah kita copot sesuai permintaan."
